# Examples

The complete integration examples are maintained beside the gateway package so they remain versioned with the API they exercise:

- [Official OpenAI JavaScript SDK client and integration tests](../apps/gateway/examples/openai-client/README.md)
- [Official OpenAI Python SDK client and integration tests](../apps/gateway/examples/python-client/README.md)
- [Framework, curl, and chatbot integration guide](../apps/gateway/docs/integrations.md)

These clients target the limited `POST /v1/chat/completions` subset. Use a model advertised or saved by the configured provider. Examples do not imply complete OpenAI API compatibility.
